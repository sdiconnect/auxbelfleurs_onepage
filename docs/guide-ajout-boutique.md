# Ajouter une boutique en 30 secondes 🌸

Guide pour Léa — aucune compétence technique nécessaire.

---

## Les 3 étapes

### 1️⃣ Ouvrir le formulaire

Dans le menu de gauche de WordPress, cliquez sur **🏪 Points de vente**,
puis sur **Ajouter**.

```
┌─────────────────────────────┐
│  Tableau de bord            │
│  📝 Articles                │
│  🏪 Points de vente   ◄──── cliquez ici, puis « Ajouter »
│  📧 Messages reçus          │
│  🎨 Apparence               │
└─────────────────────────────┘
```

### 2️⃣ Remplir la fiche

```
┌──────────────────────────────────────────────┐
│  Titre :  [ Nom de la boutique            ]   │  ← ex. « Espace Bio »
│                                                │
│  Coordonnées du point de vente                 │
│  ────────────────────────────────────────      │
│  Adresse :      [ 12 rue des Fleurs        ]   │
│  Code postal :  [ 70100 ]   Ville : [ Gray ]   │
│  Téléphone :    [ 03 84 00 00 00           ]   │
│                                                │
│  Latitude :  [ vide ]   Longitude : [ vide ]   │  ← laissez VIDE
│                                                │
│  ☑ Visible sur le site                         │  ← doit rester coché
└──────────────────────────────────────────────┘
```

- **Titre** = le nom de la boutique (c'est lui qui s'affiche sur la carte).
- **Adresse / Code postal / Ville** : le plus complet possible.
- **Latitude / Longitude** : **laissez vide** — le site trouve tout seul
  l'emplacement sur la carte quand vous enregistrez.
- **Visible** : laissez la case cochée pour que la boutique apparaisse.

### 3️⃣ Publier

Cliquez sur le bouton bleu **Publier** (en haut à droite). C'est fini ! 🎉

## Bon à savoir

**✔ Le point s'est placé au bon endroit ?**
Après la publication, un petit statut apparaît :

- 🟢 **✔ automatique réussi** → parfait, rien à faire.
- 🟣 **✎ manuel** → vous aviez saisi les coordonnées vous-même.
- 🔴 **✘ échec** → le site n'a pas trouvé l'adresse. Voir ci-dessous.

**🔴 En cas d'échec** (ou si le marqueur tombe au mauvais endroit) :

1. Allez sur [openstreetmap.org](https://www.openstreetmap.org).
2. Cherchez l'adresse, **clic droit** sur le bon endroit → « Afficher l'adresse ».
3. Notez les deux nombres (ex. `47.4460` et `5.5920`).
4. Recopiez-les dans **Latitude** et **Longitude** de la fiche, puis **Mettez à jour**.

**✏️ Modifier une boutique** : **Points de vente → Tous les points de vente**,
cliquez sur son nom. La colonne **Ville** et le statut **Géocodage** sont visibles
directement dans la liste, et vous pouvez trier par ville.

**🙈 Masquer sans supprimer** : décochez « Visible sur le site » et mettez à jour.

**📥 Ajouter beaucoup de boutiques d'un coup** : voir l'import CSV
(**Points de vente → Importer un CSV**) — pratique pour la saisie initiale.
